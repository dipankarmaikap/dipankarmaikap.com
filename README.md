# Dipankar Maikap - Personal Website

![Dipankar Maikap](https://dipankarmaikap.com/banner.png)  
Open-source personal website built with **Astro**, **MDX**, and **Tailwind CSS**.

## 🚀 Features

- **Astro**: Fast and optimized static site generation.
- **MDX**: Write content using Markdown and JSX.
- **Tailwind CSS**: Utility-first styling for a sleek and responsive design.
- **SEO Optimized**: Best practices for search engine optimization.
- **Dark Mode**: Built-in dark/light theme switching.
- **Open Source**: Free to use and contribute.

## 📂 Folder Structure

```
📦 dipankarmaikap.com
├── public/        # Static assets
├── src/
│   ├── components/  # Reusable UI components
│   ├── content/     # MDX content files
│   ├── assets/      # Images
│   ├── layouts/     # Page layouts
│   ├── pages/       # Astro pages
│   ├── tailwind.css # Global styles
│   ├── utils/       # Helper functions
├── package.json    # Dependencies and scripts
├── astro.config.mjs # Astro configuration
├── remark-reading-time.mjs # MDX plugin for timeToRead
└── tsconfig.json # Typescript configuration
```

## 📦 Installation

Clone the repository and install dependencies:

```sh
git clone https://github.com/yourusername/dipankarmaikap.com.git
cd dipankarmaikap.com
npm install
```

## 🚀 Running the Project

Start the local development server:

```sh
npm run dev
```

Build for production:

```sh
npm run build
```

Preview the production build:

```sh
npm run preview
```
